# Distribution components

| Component | Source | License |
|---|---|---|
| App, keyboard UI, decoder, icon, starter vocabulary | Independently authored LineKey source | Apache-2.0 |
| Control icon vectors | Google Material Symbols Rounded | Apache-2.0 |
| English word frequencies | Hermit Dave / FrequencyWords / OpenSubtitles 2018 | CC BY-SA 4.0 |
| English bigram statistics | WikiText-derived model, generated by project training script | CC BY-SA 3.0 |
| Emoji names, sequences and keywords | Unicode Emoji / CLDR | Unicode-3.0 |
| Google Sans | Official Google Fonts distribution | SIL OFL 1.1 |
| Material Components and AndroidX | Google / Android Open Source Project | Apache-2.0 |
| Markwon | Dimitry Ivanov / Markwon | Apache-2.0 |
| commonmark-java and GFM tables | commonmark-java contributors | BSD 2-Clause |
| Gradle wrapper | Upstream Gradle | Apache-2.0 |

Runtime dependencies: Android public framework, this project's Java core module, Material Components/AndroidX, Markwon and commonmark. Gradle merges their Java bytecode into APK DEX entries; no native library is shipped. See UI_LIBRARIES.md and the bundled Apache/BSD license texts. Source attribution and full licenses remain bundled.

The source archive excludes build caches, local SDK settings, compiled artifacts and research material. Branding cleanup affects documentation and notices; it does not change keyboard behavior.
