# Keyboard control icons

Google Material Symbols Rounded, regular weight 400, optical and intrinsic size 24dp, from the official [Material Design Icons repository](https://github.com/google/material-design-icons). Apache-2.0, Copyright Google LLC. These open vectors provide a standard Material keyboard appearance; exact proprietary Gboard artwork is not claimed. Microphone and emoji controls are monochrome vector icons rather than emoji text. Shift retains outline/fill states, and Caps Lock adds an independently drawn underline to the regular filled arrow. Resource filenames are prefixed, and the AppCompat tint attribute is removed because this app uses the public framework. Native image buttons tint and scale to available bounds.
